1
Pre-call — Da comunicare al cliente in anticipo
10 min · il cliente fa da solo prima della call

Manda questi link al cliente via messaggio prima della call. Deve solo creare gli account, non configurare nulla.

  • GitHub — github.com — Registrazione gratuita con email
  • Railway — railway.app — Si registra con l'account GitHub (un click)
  • Anthropic — console.anthropic.com — Richiede carta di credito (non addebita subito, $5 di credito gratuito)
  • Groq — console.groq.com — Gratuito, solo email
  • Voyage AI — dash.voyageai.com — Gratuito, solo email
  • Notion — notion.so — Potrebbe averlo già. Se no, gratuito
⚠️ Anthropic è l'unico che richiede carta di credito. Rassicura il cliente: non viene addebitato nulla automaticamente, i costi sono a consumo (tipicamente $3–10/mese).
2
In call — Raccolta API Key
~15 min · fai fare al cliente in sequenza

Segui questo ordine. Per ogni servizio, guida il cliente schermo condiviso e incollate la chiave in un documento temporaneo (es. un blocco note) — servirà nel prossimo step.

1 · Anthropic ANTHROPIC_API_KEY
  1. Vai su console.anthropic.com → accedi
  2. Menu sinistra → API Keys
  3. Clicca "Create Key" → nome: "Brain"
  4. Copia la chiave (inizia con sk-ant-) — viene mostrata una volta sola
⚠️ Se non ha ancora aggiunto la carta: Settings → Billing → Add payment method. Senza carta la chiave non funziona.
2 · Groq GROQ_API_KEY
  1. Vai su console.groq.com → accedi
  2. Menu sinistra → API Keys
  3. Clicca "Create API Key" → nome: "Brain"
  4. Copia la chiave (inizia con gsk_)
✓ Gratuito fino a 7.000 minuti/giorno di trascrizione — più che sufficiente.
3 · Voyage AI VOYAGE_API_KEY
  1. Vai su dash.voyageai.com → accedi
  2. Clicca su API Keys nel menu
  3. Clicca "Create new key" → nome: "Brain"
  4. Copia la chiave (inizia con pa-)
✓ Gratuito fino a 50 milioni di token/mese.
4 · Notion — Integration Token NOTION_TOKEN
  1. Vai su notion.so/my-integrations
  2. Clicca "+ New integration"
  3. Nome: "Brain" → seleziona il workspace → Submit
  4. Copia il campo "Internal Integration Secret" (inizia con secret_)
5 · Notion — Database NOTION_DATABASE_ID
  1. In Notion, crea una nuova pagina → aggiungi un blocco "Database — Full page"
  2. Nominalo "Knowledge Base"
  3. Aggiungi queste proprietà (nome esatto e tipo):
Nome proprietàTipoNote
TitoloTitleGià presente di default

  1. Connetti l'integrazione: menu … in alto a destra → Connections → aggiungi "Brain"
  2. Apri il database nel browser → copia l'ID dall'URL:
    notion.so/workspace/[QUESTO-È-IL-DATABASE-ID]?v=...
    È la stringa di 32 caratteri prima del ?
3
Fork del repo su GitHub
2 min
  1. Vai su github.com/FPTSC/tsc-brain
  2. Clicca "Use this template" → "Create a new repository"
  3. Nome repo: qualcosa tipo nomecliente-brain → Private → Create repository
4
Deploy su Railway
~8 min
  1. Vai su railway.app → New Project
  2. Seleziona "Deploy from GitHub repo" → autorizza GitHub → scegli il repo appena creato
  3. Aspetta che Railway completi il primo build (2–3 minuti)
  4. Clicca sul servizio → tab Variables → aggiungi tutte queste variabili:
VariabileValore
ANTHROPIC_API_KEYLa chiave Anthropic copiata prima
GROQ_API_KEYLa chiave Groq copiata prima
VOYAGE_API_KEYLa chiave Voyage AI copiata prima
NOTION_TOKENIl token Notion (secret_...)
NOTION_DATABASE_IDL'ID del database Notion
APP_USERUsername admin (es. admin)
APP_PASSWORDPassword admin (min. 8 caratteri)
USERS_FILE/data/users.json
  1. Crea il Volume: torna alla pagina del progetto → "+ New" → Volume → Mount Path: /data
  2. Railway fa un redeploy automatico — aspetta che diventi verde
⚠️ Railway richiede il piano Hobby ($5/mese) per il deploy continuo. Il piano gratuito va in sleep dopo inattività.
5
Primo accesso e test
5 min
  1. Railway → tab Settings → copia il dominio pubblico (es. xxx.up.railway.app)
  2. Apri il dominio nel browser → inserisci APP_USER e APP_PASSWORD impostati prima
  3. Vai su /admin → crea un account per ogni membro del team del cliente (non admin)
  4. Test finale: dalla home clicca l'icona microfono → carica un file audio di test → verifica che l'analisi arrivi correttamente
✓ Se l'analisi arriva, il sistema è completamente funzionante. Il database è vuoto — si popola man mano che vengono caricate le call.
